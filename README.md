# GameSearch

Пет-проект, демонстрирующий навыки Fullstack-разработки.  
Платформа для поиска, оценки и получения персонализированных рекомендаций видеоигр.  
Аналог функционала RAWG или Кинопоиска, но для игр.

## 🛠 Технологический стек

### Frontend

- **Фреймворк:** React / Next.js
- **Стилизация:** Tailwind CSS

### Backend

- **Платформа:** ASP.NET Core 8
- **База данных:** MongoDB

## Запуск проекта локально

### Backend (ASP.NET)

```bash
dotnet run
```

### Frontend (React / Next.js)

```bash
npm install
npm start
```
